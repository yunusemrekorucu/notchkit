## What's new

- **Choose your displays:** with more than one display connected, pick where the notch appears in **Settings → General → Displays**: all displays, only the built-in display, only the main display, or the displays you select. If none of the chosen displays is connected, NotchKit uses the main display.
- The old "Enable on screens without a notch" switch is replaced by these options, and your previous choice carries over.

## Install

1. Download **NotchKit-1.1.0.dmg** below and open it.
2. Drag **NotchKit** to **Applications** (replace the old version if asked).
3. Open NotchKit. macOS blocks the first launch because the app isn't notarized yet: go to **System Settings → Privacy & Security** and click **Open Anyway** next to the NotchKit message.

Requires macOS 14.6 or later. Runs natively on Apple silicon and Intel Macs.
